# Legesgue integral
## integration of simple functions
 
we first condsider the case of simple function(c.f.[[可测函数]]) $\phi$ is a finite sum $\phi(x) = \sum_{k=1}^Na_k \chi_{E_k}(x)$, where $E_k$ are measurable sets of finite measure and the $a_k$ are constants. A complication of this definition is the lack of uniqueness, ($0=\chi_{E}-\chi_{E}$ for example). This can be solved by defining a canonical form of $\phi$ by forcing $E_k$ to be disjoint. Takeing $c_1,\cdots,c_M$ to be all none zero value $\phi$ can take, and $F_k:=\{x:\phi(x)=c_k\}$. Now we let $$\int_{\mathbb{R}^d}\phi(x)dx=\sum_{k=1}^M c_km(F_k)$$ If $E$ is measurable subset of $\mathbb{R}^d$ with finite measure, then $\phi(x) \chi_{E}(x)$ is also a simple function, then we define the *Lebegue integral* of $\phi$ by $$\int_{E}\phi(x)dx=\int \phi(x)\chi_{E}(x)dx$$ 
## integration of bounded functions supported on set of finite measure

we then condsider the case of bounded functions supported on a set of finite measure (i.e. the set $\{x:f(x) \neq 0\}$ has finite measure.). Using the theorem proved in [[可测函数]], we can choose a sequence of simple functions $\{\phi_n(x)\}$ such that $\phi_n(x) \rightarrow f(x)$ for all $x$. 

**Lemma**:
Let $f$ be a bounded function supported on a set $E$ of finite measure. If $\{\phi_n\}$ is any sequence of simple functions bounded by $M$, supported on $E$, and with $\phi_n(x) \rightarrow f(x)$ a.e. thenL
1) The limit $\lim\limits_{n \rightarrow \infty}\int \phi_n$ exists.
2) If $f=0$ a.e., then $\lim\limits_{n \rightarrow \infty}\int \phi_n = 0$.
*Proof*:
the statement is almost obvious if $\phi_n$ converges uniformly to $f$, so we simply apply the littlewood princilple and choose a set where $\phi_n$ converges uniformly, and then we are done. We take $E_\epsilon$ such that $m(E-E_\epsilon)<\epsilon$ and $\phi_n$ converges uniformly to $f$. Because $f$ is bounded, so we $\phi_n$ is bounded uniformly, take the upperbound to be $M$, then $|\int \phi_n-\int\phi_m|<2M \epsilon+\epsilon m(E)$, so it clearly converges. And if $f=0$ a.e., then we have $|\int\phi_n| \leq m(E)\epsilon +M \epsilon$, so we are done as well.

Now with the above lemma, we can definte the *Lebegue integral* by $\int f(x)dx= \lim\limits_{n \rightarrow \infty}\int \phi_n(x)dx$. 

**Theorem**(Bounded convergence theorem):
Suppose that $\{f_n\}$ is a sequence of measurable functions that are all bounded by $M$, are supported on a set $E$ of finite measure, and $f_n \rightarrow f$ a.e. Then $f$ is measurable, bounded, supported on $E$ a.e. and $\int |f_n-f| \rightarrow 0$. 

*Proof*:
almost the same as the above lemma.

**Remark**:
the theorem actually tells us that $\lim\limits_{n \rightarrow \infty} \int f_n= \int \lim\limits_{n \rightarrow \infty}f_n$. 

## Return to Riemann integrable functions
We hope that the new definition coinside with the regular Riemann integration. 

**Theorem**:
Suppose $f$ is Riemann integrable on the closed interval $[a,b]$. Then $f$ if measurable, and $$\int_{[a,b]}^{\mathcal{R}} f(x)dx = \int_{[a,b]}^{\mathcal{L}} f(x) dx$$ where the integral on the left-hand side is the standard Riemann integral and the one on the right is the Lebegue integral.

*Proof*:
Using the fact that $f$ is Riemann integrable, we can construct two sequence $\{\phi_n\}$, $\{\psi_n\}$ of step functions, with $\phi_1 \leq \phi_2 \leq \cdots \leq f \leq \cdots \leq \psi_2 \leq \psi_1$ and $\lim\limits_{n \rightarrow \infty}\int_{[a,b]}^{\mathcal{R}} f(x)dx=\int_{[a,b]}^{\mathcal{R}} f(x)dx= \lim\limits_{n \rightarrow \infty}\int_{[a,b]}^{\mathcal{R}} \psi_n(x)dx$. One easily varify that the theorem is true for step functions, take $\tilde{\phi} = \lim\limits_{n \rightarrow \infty} \phi_n$ and $\tilde{\psi}= \lim\limits_{n \rightarrow \infty} \psi_n$ then we use the theorem we proved above, we have $\int_{[a,b]}^{\mathcal{L}}(\tilde{\phi}-\tilde{\psi})=0$, so $\tilde{\phi}=\tilde{\psi}$ a.e. so $\tilde{\phi}=\tilde{\psi}=f$ a.e., hence $f$ is measurable and then we are done.


## non-negative functions
We hope to extend the value the functions can take, i.e. they can take value $+\infty$, in which case we define the Lebegue integral by $\int f(x)dx=\sup\limits_g\int g(x)dx$ where the supremum is taken over all measurable functions $g$ such  that $0 \leq  g\leq f$ and where $g$ is bounded and supported on a set of finite measure. If $\int f(x)dx< \infty$ then we say $f$ is Legesgue integrable or integrable in short. It is clear that the definition can be extend to the general case of $E \subseteq \mathbb{R}^d$. 

**Lemma**:
Suppose that $\{f_n\}$ is a sequence of measurable functions with $f_n \geq 0$. If $\lim\limits_{n \rightarrow \infty}f_n(x)=f(x)$ a.e., then $$\int f \leq \lim\inf \int f_n$$ *Proof*:
Using the definition, we only have to proof for a measurable function $g$ with $0 \leq g \leq f$ and bounded with a support that have a finite measure, we have $\int g \leq \lim\inf \int f_n$. In fact, take $g_n=\min(g,f_n)$, then $g_n \rightarrow g$, unsing the bounded convergence theorem, we have $\int g = \lim g_n \leq \lim\inf \int f_n$.

In fact, the equality holds if $f_n \nearrow f$. 

## general case
We successfully deinfine the case of non-negative functions, so if we seperate the positive and negative parts of a general function, then we can get the genrel definition of the integration. 

**Proposition**:
Suppose $f$ is integrable on $\mathbb{R}^d$. Then for every $\epsilon>0$:
1) There is a set of finite measure $B$ such that $\int_{B^c}|f|<\epsilon$ 
2) There is a $\delta>0$ such that $\int_{E} |f|<\epsilon$ whenever $m(E)<\delta$.
*Proof*:
We may assume withoutloss that $f \geq 0$. Let $B_N$ be the ball with radius $N$, and $f_N=f \cdot \chi_N$, then $\lim\limits_{N \rightarrow \infty}\int f_N = \int f$. In particular, for large enough $N$ $0 \leq \int f - \int f_N < \epsilon$. Note  that $\chi_{B^c}=1-\chi_{B}$ so the first part is done. 
For the second part, take $E_n:=\{x:f(x) \leq N\}$. And have $\int (f-f_N)<\frac{\epsilon}{2}$, so pick $N\delta<\frac{\epsilon}{2}$ and we  have $\int_E f =\int_E(f-f_N)+\int_E f_N<\epsilon$. 

**Theorem**:
Suppose $\{f_n\}$ is a sequence of measurable functions such that $f_n \rightarrow f$ a.e.. If $|f_n(x)| \leq g(x)$, where $g$ is integrable, then $$\int |f_n -f| \rightarrow 0$$ and consequently $$\int f_n \rightarrow \int f$$
*Proof*:
Using the similar arguments above and choose $N$ such that $\int_{E_N^c}g< \epsilon$ (where $E_N:=\{x:g(x) \leq N\}$) then the part $E_N$ we use the bounded convergence theorem and the rest is less than $\epsilon$.

# The space of $L^1$ of integrable functions
We define the norm of any integrable function $f$ on $\mathbb{R}^d$ to be $\lVert f \rVert=\int_{\mathbb{R}^d}|f(x)|dx$.

**Theorem**:
The vector space $L^1$ is complete in its matric.

*Proof*:
This is not easy in general, but if we consider the case of the sequence convergence really fast, it will be much easier. As the Cauchy sequence $\{f_n\}$ tells us that $\int |f_n|$ has a limit, and we hope use the convergence theorem to get the limit. Now take the subsequence $\{f_{n_k}\}$ with $\lVert f_{n_k} - f_{n_{k+1}} \rVert \leq \frac{1}{2^n}$ then the limit $f=f_{n_1} + \sum\limits_{k=1}^{\infty}(f_{n_{k+1}}-f_{n_k})$ exists as it absolutely converges, and  we use $g(x) = |f_{n_1}|+ \sum\limits_{k=1}^{\infty}\lvert f_{n_{k+1}} - f_{n_k} \rvert$ to hold $f$, note that $g(x)$ is integrable, then $f_{n_k} \rightarrow f$ a.e. It is easy to check that the rest convergens as well.
