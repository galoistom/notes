# Legesgue integral
## integration of simple functions
 
we first condsider the case of simple function(c.f.[[可测函数]]) $\phi$ is a finite sum $\phi(x) = \sum_{k=1}^Na_k \chi_{E_k}(x)$, where $E_k$ are measurable sets of finite measure and the $a_k$ are constants. A complication of this definition is the lack of uniqueness, ($0=\chi_{E}-\chi_{E}$ for example). This can be solved by defining a canonical form of $\phi$ by forcing $E_k$ to be disjoint. Now we let $$\int_{\mathbb{R}^d}\phi(x)dx=\sum_{k=1}^M c_km(F_k)$$ If $E$ is measurable subset of $\mathbb{R}^d$ with finite measure, then $\phi(x) \chi_{E}(x)$ is also a simple function, then we define the *Lebegue integral* of $\phi$ by $$\int_{E}\phi(x)dx=\int \phi(x)\chi_{E}(x)dx$$ 
## integration of bounded functions supported on set of finite measure

we then condsider the case of bounded functions supported on a set of finite measure (i.e. the set $\{x:f(x) \neq 0\}$ has finite measure.). Using the theorem proved in [[可测函数]], we can choose a sequence of simple functions $\{\phi_n(x)\}$ such that $\phi_n(x) \rightarrow f(x)$ for all $x$.
